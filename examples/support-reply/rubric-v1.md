# Support reply rubric (v1, original)

A typical rubric, the kind many teams write for support QA or as an LLM-as-judge prompt. Score each criterion from 1 (poor) to 5 (excellent).

| ID | Criterion | Weight | Description |
|---|---|---|---|
| C1 | Helpfulness | 30% | The response fully addresses the customer's issue and provides helpful information. |
| C2 | Empathy and tone | 20% | The response shows empathy and uses a warm, professional tone. |
| C3 | Thoroughness | 20% | The response is comprehensive and covers all relevant details. |
| C4 | Clarity and structure | 15% | The response is well organized and easy to read. |
| C5 | Accuracy | 15% | The information provided is correct. |
